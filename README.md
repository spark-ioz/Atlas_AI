# ATLAS AI – Report Studio

Elegant report generator inspired by refined product UI. Upload multi-page **PDF or DOCX** samples, choose a style mode, generate matching reports, export PDF/DOCX, and keep a **Library** of past work.

## What’s included

- **Logo**: ATLAS AI brand mark on home
- **UI**: Cream / sage palette (MOYA-inspired), light by default, dark toggle
- **Sample upload**: PDF **and** DOCX, multi-page academic reports (up to ~40 pages / 120k chars)
- **Modes**: Style Clone · Executive · Research · Creative — each opens studio with that mode
- **Library**: Bottom nav → Library lists every generated report; Open / Delete
- **No dead buttons**: Premium removed; every control has a real action
- **Bottom nav**: Home · Create · Library

## Build

Open `AtlasAI` in Android Studio → sync → Run (API 26+).

## Usage

1. **Style Clone** → upload your sample (e.g. Memory-Mapped I/O report PDF/DOCX) → enter topic → Generate  
2. Other modes work with topic only (sample optional)  
3. Export PDF, DOCX, or both → files appear in Library
